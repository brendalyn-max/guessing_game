A simple Java number guessing game.
A simple Java number guessing game built as part of a software engineering assignment.

## Features
- The computer selects a random number between 1 and 100.
- Players receive "Too low" or "Too high" hints for each guess.
- Displays a victory message with the total number of attempts once guessed correctly.

## How to Run
1. Clone the repository.
2. Open the project in IntelliJ IDEA.
3. Run the main Java application file.
